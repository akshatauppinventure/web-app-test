# Secrets schema (ADR-0016)

Every deployed secret, by host. `gen` = generated by `scripts/secrets/gen-secrets.sh`; `owner` = supplied by the owner
(from a provider console) and entered into the SOPS file by hand. Files land in `/etc/app/secrets/<name>` (mode 0400,
owned by the consuming container's UID) unless a path is given. Edge secrets go only to VPS-A, core secrets only to VPS-B.

| Name | Source | Consumer (UID) | Rotation |
|---|---|---|---|
| `crowdsec_bouncer_key` | gen (64 hex) | traefik plugin (65532) and crowdsec bouncer registration (0) — same value, two Compose secret names | 6 months |
| `crowdsec_enroll_key` | owner (CrowdSec console) or `unset` | crowdsec (0) | on console re-enrollment |
| `auth_secret` | gen (48 chars) | frontend Auth.js cookie encryption (1000) | 6 months (logs everyone out) |
| `web_bff_client_secret` | gen (48 chars); **must equal the core copy** | frontend (1000) | 6 months, together with core |
| `portainer_agent_secret` | gen (48 chars); **must equal the core copy** | portainer agent (0) | 6 months, together with core |

Not secrets (Portainer stack environment): `ACME_EMAIL`, `ACME_CA_SERVER`, `GOOGLE_CLIENT_ID`, `PUBLIC_HOST`, `CORE_BIND_IP`.
Local development uses `.dev-secrets/` (gitignored) generated by `scripts/dev/gen-dev-secrets.sh` instead of SOPS.
